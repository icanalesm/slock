# My fork of slock

Forked from [https://git.suckless.org/slock](https://git.suckless.org/slock) with the following patches:

* [dpms](https://tools.suckless.org/slock/patches/dpms)

## Requirements

To build slock, the libX11 header files are required.

## Installation

```
git clone https://github.com/icanalesm/slock.git
cd slock
make
sudo make install
```
